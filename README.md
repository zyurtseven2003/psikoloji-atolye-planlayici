Psikoloji Atölyesi Planlayıcısı

Proje Hakkında

Bu proje, psikoloji atölyelerinin planlanmasını kolaylaştırmak amacıyla Python programlama dili kullanılarak geliştirilmiştir.

Program, kullanıcıdan atölye konusu, katılımcı sayısı, grup kapasitesi ve etkinlik süresi bilgilerini alır.

Programın Özellikleri

Kullanıcıdan gerekli bilgileri alır.
Hatalı girişleri kontrol eder.
Katılımcı sayısına göre gerekli grup sayısını hesaplar.
Katılımcıların gruplara dağılımını gösterir.
Birden fazla atölye planlamaya olanak tanır.
Sonuçları atolye_plani.txt dosyasına kaydeder.

Fonksiyonlar
if-else karar yapıları
Döngüler
Listeler
Dosya işlemleri
Örnek Uygulama

Atölye konusu: Stres Yönetimi

Katılımcı sayısı: 23

Grup kapasitesi: 10

Etkinlik süresi: 60 dakika

Gerekli grup sayısı: 3

Gruplardaki kişi sayıları: 10, 10, 3
